# EXP-008 — Price Disclosure → Collector Intent

This directory is a **prelaunch preparation package**. It is deliberately not live yet.

## Single experimental variable

Whether the proposed collector price (**0.01 ETH**) is visible **before** the visitor opens acquisition details.

- CONTROL: no upfront price.
- TREATMENT: 0.01 ETH visible upfront.
- Both variants see the same artwork.
- Both variants use the same CTA: **View acquisition details**.
- After that click, both variants see exactly the same price, disclosure, confirmation button and decline button.

## Primary outcome

`collector_intent_confirm_rate_per_page_view_session`

A confirmation means only: anonymous stated willingness to consider collecting at 0.01 ETH.

It is **not** a sale, offer, marketplace visit, revenue event or profit.

## Prelaunch status

`PRELAUNCH_PREPARED_AWAITING_INFRASTRUCTURE`

Do not launch until the collector endpoint and D1 database placeholders are replaced and validated end-to-end.

No blockchain transaction or financial action is part of this package.
